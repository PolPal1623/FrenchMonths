# FrenchMonths

Одностраничный тренажёр для изучения французских месяцев.

## Live

- GitHub Pages: <https://polpal1623.github.io/FrenchMonths/>
- Репозиторий: <https://github.com/PolPal1623/FrenchMonths>

## Что внутри

- 12 месяцев без повторов в каждой сессии.
- Два типа вопросов: ввод французского названия и выбор перевода.
- Ввод без строгой привязки к диакритике.
- История ответов и финальный экран с результатом.
- Светлая и тёмная тема, синхронизация с системной настройкой.

## Запуск

1. Откройте `index.html` в браузере.
2. Сборка и зависимости не нужны.

## Редактирование

- Словарь находится в `monthsData`.
- Количество раундов автоматически равно длине словаря.
- Все стили и сценарии находятся в одном HTML-файле.
